# Apollo 11 Lunar Lander

A browser-based lunar landing game inspired by the Apollo 11 mission. Pilot the Apollo Lunar Module toward the Moon's surface, control your descent, and try to land safely in the designated landing zone.

## Play the Game

**Live Demo:** https://747aviation-nasastardance.github.io/Stardance-Lunar-Lander-Game/

## Features

- Apollo Lunar Module landing gameplay
- Lunar surface with uneven terrain and a designated landing zone
- Main engine and reaction control system (RCS) controls
- Flight information display, including velocity, altitude, and descent rate
- Fuel system with fuel consumption and a visual fuel indicator
- Landing detection and crash handling
- Mission briefing, landing, and crash screens
- Reset functionality to try the landing again

## Controls

| Key | Action |
|---|---|
| Up Arrow | Main engine thrust |
| Down Arrow | Reverse RCS thrust |
| Left Arrow | Left RCS control |
| Right Arrow | Right RCS control |
| R | Reset the mission |

## Technologies Used

- HTML
- CSS
- JavaScript
- HTML Canvas

## How to Play

1. Open the live demo.
2. Read the mission briefing and controls.
3. Use the engine and RCS controls to manage your descent.
4. Monitor your altitude, velocity, descent rate, and remaining fuel.
5. Aim for the designated landing zone and try to complete a safe landing.

## Development

This project was developed as part of NASA Stardance. I built the game using HTML, CSS, and JavaScript, implementing the landing mechanics, flight controls, terrain, HUD, fuel system, and landing/crash logic.

The project helped me practise JavaScript programming, canvas-based rendering, game physics, input handling, and debugging.
